# Artistry – Review 1

## Run the project

1. Extract the ZIP file.
2. Open the `online-art-gallery-react` folder in VS Code.
3. Open the VS Code terminal in that folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually `http://localhost:5173/`).

## Review 1 design updates

- Reworked login and signup into responsive, full-height split layouts.
- Added consistent typography, form sizing, labels, focus states and error/success messages.
- Refined the storefront hero and featured artwork layout for desktop and mobile screens.
- Made the shared site shell and page roots use the available viewport width.
- Kept React Router as a project dependency; `npm install` installs it from `package.json`.

Do not copy individual source files into the old project. Use this extracted project folder as one complete project.
